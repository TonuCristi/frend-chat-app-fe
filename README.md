# 💬 Real-Time Chat Application (Frontend)

A modern real-time chat application frontend built with React (Vite), focused on performance, responsive design, and smooth user experience.

This part of the application handles the UI, user interactions, and real-time messaging through WebSockets connected to the backend service.

---

## 🚀 Features

- User authentication (login & registration)
- Account and profile management
- Real-time messaging interface using WebSockets
- Instant message updates between users
- Responsive and modern UI design
- Form validation and error handling
- State management for UI and server data

---

## 🧠 Tech Stack

- React (Vite)
- Tailwind CSS
- React Hook Form
- Zod
- React Query
- Zustand
- WebSockets (client-side integration)

---

## 🛠️ Key Concepts Implemented

- Real-time UI updates via WebSockets
- Authentication flow handling (login/register)
- Global state management (Zustand)
- Server state management (React Query)
- Form validation (Zod + React Hook Form)
- Responsive UI/UX design
